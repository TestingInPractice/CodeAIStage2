# Mobile App Development

## When to use
- User is building a mobile app
- Need help with React Native, Flutter, or native code
- UI/UX for mobile screens
- Platform-specific APIs and deployment

## Capabilities

### React Native
- Components and hooks
- Navigation (React Navigation)
- State management (Redux, Zustand)
- Native modules

### Flutter
- Widgets and layouts
- State management (Provider, Riverpod)
- Platform channels
- Custom painters

### Native iOS
- SwiftUI and UIKit
- Core Data
- CloudKit
- App Store deployment

### Native Android
- Jetpack Compose
- Room database
- Google Play deployment
- Material Design

## Workflow

1. **Platform choice** — Which framework/platform?
2. **Architecture** — Plan app structure and navigation
3. **Implement** — Write components and logic
4. **Test** — Simulator/emulator and device testing

## Best Practices

- Responsive layouts for different screens
- Handle safe areas and notches
- Optimize for battery and performance
- Follow platform guidelines (HIG/Material)
- Implement proper error handling

## Common Patterns

- MVVM or Clean Architecture
- Repository pattern for data
- BLoC or Provider for state
- Deep linking setup
