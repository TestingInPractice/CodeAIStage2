# Добавление записей в базу знаний

## Когда использовать
- Пользователь хочет добавить статью/видео/книгу/концепцию в базу знаний
- Пользователь предоставил стенограмму видео для обработки
- Пользователь хочет обработать файл из предоставленной папки
- Нужно обновить INDEX.md и синхронизировать с Graph RAG

## Workflow

### Шаг 1: Определить тип записи
Спросите у пользователя:
1. **article** — статья, пост, документация
2. **video** — видео (с обработкой стенограммы)
3. **book** — книга, длинная документация
4. **concept** — концепция, паттерн, термин

### Шаг 2: Собрать метаданные
Обязательные поля:
- `source` — URL или путь к файлу
- `date` — дата добавления (сегодня)
- `tags` — ключевые слова (3-7)

Опциональные:
- `author` — автор
- `rating` — оценка 1-5
- `status` — processed/draft

### Шаг 3: Создать заметку

#### Для article:
Используйте шаблон `templates/article.md`.

#### Для video (workflow обработки стенограммы):
1. Создайте файл `videos/YYYY-MM-DD-title-transcript.md` из шаблона `templates/video-transcript.md`
2. Заполните сырую стенограмму с таймкодами
3. Обработайте стенограмму → создайте `videos/YYYY-MM-DD-title.md` из шаблона `templates/video.md`
4. Удалите или переместите transcript в archive

**Формат стенограммы (сырой):**
```
## [00:00:00] Вступление
Приветствую. Сегодня мы поговорим о...

## [00:05:30] Основная часть
Ключевая идея в том, что...
```

**Обработка стенограммы → заметка:**
- Извлеките ключевые тезисы
- Структурируйте по темам (без таймкодов)
- Сохраните цитаты дословно
- Добавьте ссылки на релевантные концепции

#### Для book:
Используйте шаблон `templates/book.md`.

#### Для concept:
Используйте шаблон `templates/concept.md`.

### Шаг 4: Обновить INDEX.md
Добавьте запись в соответствующую таблицу в `docs/knowledge/INDEX.md`.

### Шаг 5: Синхронизировать с Graph RAG
**Обязательно!** После добавления/обновления заметки синхронизируйте с graph-mem:

```bash
# Полная синхронизация Obsidian → Graph
python3 scripts/sync-obsidian-graph.py md2graph

# Или ручное добавление через MCP-инструменты:
# 1. search_nodes — проверить, нет ли дубликата
# 2. add_entities — добавить сущность
# 3. add_observations — добавить наблюдения
# 4. add_relationships —建立 связи с существующими сущностями
```

**Важно:** Всегда проверяйте на дубликаты через `search_nodes` перед добавлением!

### Шаг 6: Обновить sources.json (опционально)
Если источник не в `docs/sources.json`, добавьте через `gsd-add-source`.

### Шаг 7: Готово
Покажите пользователю что создано:
- Путь к файлу
- Краткое описание
- Рекомендации по связанным заметкам
- Статус синхронизации с Graph RAG

## Шаблоны
- `templates/article.md` — статья
- `templates/video-transcript.md` — сырая стенограмма
- `templates/video.md` — обработанное видео
- `templates/book.md` — книга/документация
- `templates/concept.md` — концепция

## Критерии качества
- Все обязательные YAML-поля заполнены
- Есть хотя бы 3 тега
- Есть связанные заметки (related)
- INDEX.md обновлён
- Graph RAG синхронизирован (без дубликатов)

## Инструменты
- Write: создание .md файлов
- Edit: обновление INDEX.md
- gsd-add-source: добавление в sources.json (опционально)
- graph-mem MCP: синхронизация с графом знаний
- sync-obsidian-graph.py: двунаправленная синхронизация

## Graph RAG MCP инструменты
| Инструмент | Когда использовать |
|------------|-------------------|
| `search_nodes` | Проверка на дубликаты перед добавлением |
| `add_entities` | Добавление новой сущности |
| `add_observations` | Обогащение контекста |
| `add_relationships` |建立 связи между заметками |
| `find_connections` | Поиск связанных сущностей |
| `get_entity` | Получение полного контекста |
