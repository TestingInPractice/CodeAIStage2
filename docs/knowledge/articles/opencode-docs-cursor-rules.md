# Cursor Rules — что полезно для OpenCode

> **Источник:** https://cursor.com/ru/docs/rules

---

**Cursor читает `AGENTS.md` из корня проекта** — значит один `AGENTS.md` работает и в OpenCode, и в Cursor. Контент-рекомендации те же: коротко, конкретно, с `@`-ссылками на файлы (идентично doc 38).

Остальное (`*.mdc` с YAML frontmatter, Team Rules, Nested AGENTS.md, Remote Rules) — Cursor-специфика, к OpenCode не относится.
