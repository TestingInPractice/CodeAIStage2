# gsd-skill-system--claude-code

## Описание
Система скиллов Claude Code — способ расширения возможностей агента через SKILL.md файлы в ~/.opencode/skills/. Каждый скилл определяет workflow, инструкции и ресурсы для конкретной задачи. Автоматически загружается при совпадении контекста.
