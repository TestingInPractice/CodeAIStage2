# hermes-multi-agent-system

## Описание
Мультиагентная система, построенная на паттерне OODA-петли Джона Бойда. Реализует делегирование задач подагентам через оркестратор с двухуровневой архитектурой (macro + micro OODA). Каждый агент получает контекстную изоляцию и общается через файлы в поддиректориях.
