- URL: https://github.com

## Основная idea
Платформа для хостинга Git-репозиториев с совместной разработкой, issue tracking, CI/CD (GitHub Actions), иPull Requests.

## Ключевые моменты
- **Remote** — основное хранилище кода
- **Pull Requests** — процесс code review
- **GitHub Actions** — автоматизация CI/CD
- **Issues** — трекинг задач
- **Copilot** — AI-ассистент для кодинга
