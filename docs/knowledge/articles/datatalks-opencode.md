# DataTalks.ru OpenCode Guide

## Источник
- URL: https://datatalks.ru/opencode
- Дата чтения: 2026-07-22
- Ключевые слова: OpenCode, stage-based delivery, skills, agents

## Основная идея
Руководство по OpenCode — описывает stage-based delivery подход, использование скиллов, архитектуру агентов и best practices для multi-agent систем.

## Ключевые моменты
- **Stage-based delivery**: каждая фаза = discuss → plan → execute → verify
- **Скиллы**: модульные пакеты знаний для агентов
- **Агенты**: определены через .md файлы с ролями и инструкциями
- **Task tool**: делегирование задач подагентам

## Практическое применение
Основа для GSD (Get Stuff Done) workflow:
- gsd-discuss-phase → gsd-plan-phase → gsd-execute-phase → gsd-verify-work
- Все фазы проекта CodeAIStage2 следуют этому подходу
