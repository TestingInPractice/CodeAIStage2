# ooda-loop--wikipedia

## Описание
Статья о петле ОБНК (Observe-Orient-Decide-Act) — модели принятия решений, разработанной Джоном Бойдом для военной стратегии. Описывает四个阶段 цикла: наблюдение, ориентация, решение, действие. Модель используется для быстрого адаптивного реагирования в условиях неопределённости.
