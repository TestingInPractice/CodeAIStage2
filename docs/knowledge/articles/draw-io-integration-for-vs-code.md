# draw-io-integration-for-vs-code

## Описание
Расширение VS Code для визуального редактирования .drawio файлов прямо в IDE. Поддерживает drag-and-drop редактирование, автосохранение, экспорт в PNG/SVG. Открывает .drawio как визуальный редактор вместо текстового кода.

## Ключевые факты
