# skill-creator

## Источник
- URL: https://skills.sh/anthropics/skills/skill-creator
- Дата чтения: 2026-07-25
- Ключевые слова: skills, creation, authoring, publishing

## Основная идея
Официальный скилл от Anthropic (327.8K установок) для создания новых SKILL.md файлов. Помогает спроектировать структуру, написать инструкции и опубликовать скилл.

## Ключевые моменты
- YAML frontmatter: name, description, license, compatibility
- Секция "Когда использовать" — триггеры активации
- Инструкции по шагам — workflow скилла
- Примеры использования
- Интеграция с `npx skills init` и `npx skills publish`

## Практическое применение
Используется для создания кастомных скиллов:
- gsd-add-source — учёт источников
- knowledge-add — добавление знаний

## Связи

- [[gsd-add-source]] — созданный скилл

## Заметки
Anthropic поддерживает стандарт SKILL.md. Все скиллы совместимы с Claude Code, OpenCode, Cursor и др.
