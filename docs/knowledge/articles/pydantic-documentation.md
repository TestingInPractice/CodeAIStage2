# pydantic-documentation

## Описание
Документация Pydantic — библиотеки валидации данных на основе аннотаций Python. Обеспечивает автоматическую валидацию, сериализацию, и генерацию JSON Schema. Интегрирована с FastAPI, LangChain и другими фреймворками.
