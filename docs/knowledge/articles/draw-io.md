# draw-io

## Описание
Бесплатный онлайн-редактор диаграмм и схем. Поддерживает экспорт в PNG, SVG, PDF, XML. Интеграция с VS Code через расширение hediet.vscode-drawio для визуального редактирования .drawio файлов прямо в IDE.
