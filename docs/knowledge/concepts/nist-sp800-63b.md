# NIST SP 800-63B

## Определение
Рекомендации NIST (National Institute of Standards and Technology) по управлению цифровой идентификацией. Основной стандарт для парольной политики в США и за рубежом.

## Суть
Ключевые требования к паролям:
- Минимальная длина 64 символа (разрешены Unicode и пробелы)
- Проверка по спискам утёкших паролей (Have I Been Pwned)
- Запрет на хеширование без соли
- Запрет на подсказки паролей
- Мультифакторная аутентификация рекомендуется

## Применимые требования
1. Пароли не должны храниться в открытом виде
2. Использовать адаптивное хеширование (bcrypt/scrypt/Argon2)
3. Проверять по базам утёкших паролей
4. Не ограничивать спецсимволы в паролях
