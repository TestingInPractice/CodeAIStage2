# Hermes Multi-Agent System

## Определение
Мультиагентная система, построенная на паттерне OODA-петли Джона Бойда. Реализует делегирование задач подагентам через оркестратор с двухуровневой архитектурой (macro + micro OODA).

## Суть
Hermes — это архитектурный прототип, на основе которого построен orchestrator-v2 проекта CodeAIStage2. Ключевые паттерны:
- Оркестратор управляет workflow и делегирует подагентам
- Каждый агент получает контекстную изоляцию (только свои файлы)
- Агенты общаются через файлы в поддиректориях (subtasks/)
- Двухуровневая OODA: macro для оркестратора, micro для каждого агента

## Элементы / компоненты
1. Orchestrator — управление 13-шаговым процессом
2. Analyst — проверка полноты задачи
3. Developer — написание кода и тестов
4. Tester — тестирование и валидация
5. Security — аудит безопасности
