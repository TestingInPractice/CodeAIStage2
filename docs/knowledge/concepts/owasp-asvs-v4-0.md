# owasp-asvs-v4-0

## Описание
Application Security Verification Standard — стандарт верификации безопасности приложений от OWASP. Содержит требования к аутентификации, управлению сессиями, валидации данных, шифрованию и др. Уровни верификации: L1 (базовый), L2 (средний), L3 (высокий).
