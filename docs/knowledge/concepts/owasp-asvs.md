# OWASP ASVS v4.0

## Определение
Application Security Verification Standard — стандарт верификации безопасности приложений от OWASP. Содержит требования к аутентификации, управлению сессиями, валидации данных, шифрованию.

## Суть
ASVS определяет три уровня верификации:
- **L1** — базовый (для всех приложений)
- **L2** — средний (для приложений с персональными данными)
- **L3** — высокий (для финансовых/медицинских систем)

Проект CodeAIStage2 целится на **L2**.

## Ключевые требования (применимые)
- **2.1.3** — Хеширование паролей (bcrypt, scrypt, Argon2)
- **4.1.1** — Управление учётными записями
- **12.5.3** — Хранение секретов (не в коде)
